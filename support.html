Hilfe & Support

Fragen, Fehler oder Wünsche? Schreib an support@connexa-gmbh.ch – wir antworten in der Regel innerhalb von zwei Werktagen.

Wie richte ich eine Kamera ein?

Auf dem Gerät, das filmen soll: SpareCam öffnen, Zugangscode festlegen, unter Einstellungen → Kamera-Code für Fernansicht einen Code mit mindestens 6 Zeichen eintragen und den Tab Aufnahme offen lassen. Auf dem zweiten Gerät: Tab Fernansicht → + → denselben Code eingeben → Kameras suchen und hinzufügen.

Die Fernansicht findet meine Kamera nicht.

  • Auf der Kamera muss der Tab „Aufnahme“ geöffnet sein, und dort muss ein Kamera-Code gesetzt sein (oben steht sonst „Fernansicht aus“).
  • WLAN und Bluetooth müssen auf beiden Geräten eingeschaltet sein. Ein gemeinsames WLAN ist nicht nötig.
  • In den iOS-Einstellungen → SpareCam muss „Lokales Netzwerk“ erlaubt sein.
  • Beide Geräte brauchen die neueste Version von SpareCam. Die Geräte müssen in der Nähe sein (gleiche Wohnung oder Haus).

Was macht der Akkuspar-Modus?

Er schaltet den Bildschirm schwarz und dimmt ihn, damit ein aufgestelltes Gerät lange durchhält. Kamera und Fernansicht laufen weiter. Während einer Aufnahme zeigt oben eine rote „REC“-Anzeige die Aufnahme an. Beenden: etwa 1,5 Sekunden lang auf den Bildschirm drücken. Für Dauerbetrieb empfehlen wir ein Ladekabel.

Wo sind meine Aufnahmen, und wie sichere ich sie?

Im Tab Galerie (mit eigener PIN). Über Auswählen → Sichern-Symbol landen sie in Fotos, in Dateien oder per AirDrop auf einem anderen Gerät. SpareCam lädt nichts in eine Cloud.

Ich habe meinen Zugangscode vergessen.

Aus Sicherheitsgründen gibt es keine Hintertür. Du kannst SpareCam löschen und neu installieren; dabei werden auch die gespeicherten Aufnahmen gelöscht.

Darf ich andere Personen filmen?

Nur mit ihrer Einwilligung und im Rahmen der Gesetze an deinem Ort. SpareCam ist für die eigene Wohnung, Haustiere und eigenes Grundstück gedacht.

Help & support

Questions, problems or ideas? Write to support@connexa-gmbh.ch – we usually reply within two business days.

How do I set up a camera?

On the device that should record: open SpareCam, set a passcode, enter a code of at least 6 characters under Settings → Camera code for remote view and leave the Record tab open. On the second device: Remote tab → + → enter the same code → Find and add cameras.

The remote view doesn't find my camera.

  • The Record tab must be open on the camera, and a camera code must be set there (otherwise it shows “Remote off”).
  • Wi-Fi and Bluetooth must be on on both devices. A shared Wi-Fi network is not needed.
  • In iOS Settings → SpareCam, “Local Network” must be allowed.
  • Both devices need the latest version of SpareCam and must be nearby (same home).

What does battery saver do?

It turns the screen black and dims it so a set-up device lasts a long time. The camera and remote view keep running. While recording, a red “REC” indicator at the top shows the recording. To exit, press the screen for about 1.5 seconds. For continuous use we recommend a charging cable.

Where are my recordings, and how do I save them?

In the Gallery tab (with its own PIN). Use Select → save icon to put them in Photos, Files or send them via AirDrop. SpareCam never uploads anything to a cloud.

I forgot my passcode.

For security there is no back door. You can delete and reinstall SpareCam; this also deletes the stored recordings.

May I film other people?

Only with their consent and within the laws where you are. SpareCam is meant for your own home, pets and property.
